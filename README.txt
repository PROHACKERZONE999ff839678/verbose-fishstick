PRO HACKER ZONE WEBSITE
=======================

Included:
- Responsive HTML/CSS/JavaScript frontend
- Python Flask backend
- Search filter for the game cards
- Mobile navigation menu
- Example /api/games JSON endpoint

RUN ON A COMPUTER
1. Install Python 3.
2. Open a terminal in this project folder.
3. Install dependencies:
      python -m pip install -r requirements.txt
4. Start the site:
      python app.py
5. Open http://127.0.0.1:5000 in your browser.

RUN ON ANDROID
- You can edit the files in an Android code editor.
- To run the Python backend locally, install a Python environment such as
  Termux from its official source, install the requirements, then run app.py.
- For a public website, deploy the Flask app to a Python-compatible host.

CUSTOMIZE
- Edit templates/index.html for page text and sections.
- Edit static/style.css for colors, spacing and layout.
- Edit static/app.js for frontend interactions.
- Edit GAMES in app.py to change the game cards.

IMPORTANT
- This is a front-end demo with sample game cards. Replace the # links with
  your own legitimate social pages, app pages and authorized download URLs.
- Do not upload modified game clients or files that violate game rules,
  copyright, or device security.
- C++ and Java are not required for this website. They are useful for other
  kinds of native apps or separate backend services, but should not be mixed
  into this basic Flask website.
